# Source assets supplied for this project

- HMP_100_Language_Starter.zip: language picker controller and 100-language list (integrated).
- H_Media_Player_Glassmorphism_Icon_Pack.zip: 53 glass icons and the launcher icon (integrated).
- H_Media_Player_Universal_Icon_Themes.zip: 7 themes x 374 icons, not wired yet (for the theme gallery).
- VoidEngine_fixed_v2.zip: original engine source; the integrated module is in voidengine/.
- custcli-main.zip: a reference coding-agent CLI (MIT licence, kept with its licence). Ideas only; no code is used in the app.
