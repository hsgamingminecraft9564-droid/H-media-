# Put the website online (GitHub Pages)

The website is in the website/ folder. GitHub Pages publishes it for free, from the pages.yml workflow.

## One-time setup

1. On GitHub, open your repo, then Settings, then Pages.
2. Under Build and deployment, set Source to **GitHub Actions**.
3. Push the code. The **Website (GitHub Pages)** workflow runs on the Actions tab.
4. When it finishes, the site address appears on the Pages settings page. It looks like
   https://hsgamingminecraft9564-droid.github.io/H-media-/

## Changing the website

Edit the files in website/, commit and push. The workflow publishes the change by itself.

## Checking it

- Open the address on your phone and tap Download for Android.
- Check the Support and Privacy pages.
- Update the version text and the download notes when you release a new version.

## Notes

- Support questions go to GitHub Issues. If you want an email address as well, add it to website/support.html.
- The privacy page is a plain summary. Have it reviewed before you publish the app widely.
